# Моды StabCam (`.module`)

Мод — один JSON-файл. В нём нет кода: он может только менять **разрешённые настройки**, добавлять **LUT-ы**, **пресеты** и свои **ползунки**. Установка: Настройки → **Моды** (из файла, по ссылке, из буфера или из каталога). Файл `.module` можно открыть прямо из «Файлов»/мессенджера через «Открыть с помощью → StabCam».

## Создать мод с помощью нейросети

1. Моды → **Скопировать промпт для нейросети**. В промпт автоматически вставляются модель, чип, Android, возможности вашей камеры (режимы записи, OIS, HLG, high-speed, размеры сенсора) и текущий конфиг. Нейросеть просят **найти в интернете** характеристики телефона и подобрать значения.
2. Вставьте промпт в чат с ИИ и допишите задачу, например:
   * «базовый мод с правильными параметрами для моего телефона»;
   * «ночной профиль: максимум шумоподавления без сильного нагрева»;
   * «кинематографичный стиль с ползунком силы цвета».
3. Скопируйте ответ ИИ **целиком** → **Вставить мод из буфера**.
4. Приложение чинит типичные ошибки ИИ: убирает ```-оформление и комментарии, лишние запятые, типографские кавычки, лишний текст вокруг, и дописывает скобки у обрезанного ответа (об этом скажет окно установки).
5. В окне установки видно, кто автор, подходит ли мод вашему телефону, и **что именно изменится** («Шумоподавление 0.5 → 0.7»). Можно поставить сразу включённым или выключенным.

## Формат

```jsonc
{
  "module": 1,                           // версия формата, обязательно
  "id": "user.my-mod",                   // a-z 0-9 . - _ ; 3–64 символа; по нему мод обновляется
  "name": "Название", "icon": "🎬", "author": "", "version": "1.0",
  "description": "Что делает.",

  "match":   { "manufacturer": ["OnePlus"], "model": ["CPH2767"] },  // для каких устройств (необязательно)
  "depends": ["base.oneplus-15r"],       // нужны ли другие моды (необязательно)

  "config":  { "stab": { "denoise": "${denoise}" }, "video": { "quality": "4K60" } },

  "settings": [                          // свои элементы управления мода (необязательно)
    { "key": "denoise", "title": "Шумоподавление", "type": "slider", "min": 0, "max": 1, "step": 0.05, "default": 0.5 },
    { "key": "hdr",     "title": "HDR", "type": "toggle", "default": false },
    { "key": "style",   "title": "Стиль", "type": "choice",
      "options": [ { "label": "Мягкий", "value": 0.4 }, { "label": "Сильный", "value": 0.8 } ], "default": 0.4 }
  ],

  "luts":    [ { "name": "Мой стиль", "cube": "LUT_3D_SIZE 17\n0 0 0\n…" } ],
  "presets": [ { "name": "Прогулка", "config": { "stab": { "crop": 1.1 } } } ]
}
```

* **`match`** — те же ключи, что у пресетов устройств: `manufacturer`, `brand`, `model`, `device`, `socManufacturer`, `socModel`. Сравнение по подстроке без учёта регистра. Мод с другим `match` ставится, но с пометкой «⚠ другое устройство».
* **`settings` + `"${ключ}"`**: если в `config` значение — строка вида `"${denoise}"`, подставляется выбранное пользователем число/флаг/текст (тип сохраняется). Элементы мода появляются в его карточке в списке установленных.
* **`luts`**: `cube` — текст 3D `.cube`, значения 0..1, красный канал меняется быстрее всего, строк ровно `размер³`. Стиль появится в списке LUT с подписью «мод · название».
* **`presets`**: именованные наборы настроек, применяются одним нажатием в списке «Пресеты из модов».

### Разрешённые ключи `config`

| Группа | Ключи |
|---|---|
| Видео | `video.quality` (`4K120` `4K60` `4K30` `3.3K60` `1080p60` `1080p30`), `video.codec` (`hevc` `avc`), `video.hdr` (`off` `hlg10`), `video.audio`, `video.bitrateScale` (0.5–2), `video.lut`, `video.lutStrength` (0–1) |
| Стабилизация | `stab.enabled`, `stab.crop` (1.0–1.25), `stab.minCrop`, `stab.maxAngleDeg` (2–10), `stab.tauMaxMs` (100–1500), `stab.tauMinMs`, `stab.velTauMs`, `stab.sharpen` (0–1), `stab.bicubic`, `stab.denoise` (0–1), `stab.denoiseSigma`, `stab.timeOffsetMs` (−10…10) |
| Камера | `camera.ois`, `camera.stockEis`, `camera.noiseReduction` / `camera.edge` / `camera.distortionCorrection` (`off` `fast` `hq`), `camera.forceAllQualities` |
| Интерфейс | `ui.showInfo`, `ui.mode` (`simple` `pro`), `post.enabled`, `post.bitrateFactor`, `post.exportGcsv` |

Всё остальное отклоняется (в том числе адрес обновлений `update.*` и vendor-ключи камеры).

## Комбинирование

Включённые моды накладываются **по порядку списка**, поверх пресета устройства и под вашими ручными правками:

`по умолчанию → пресет устройства → мод 1 → мод 2 → … → ваши настройки`

Если два мода меняют один параметр, **побеждает нижний в списке**; приложение показывает такие пересечения. Порядок меняется стрелками ▲▼ в карточке. Хороший приём: «**база для телефона**» (OIS, режимы, кодек; ставится первой) + «**стиль**» (LUT, плавность) + «**профиль**» (ночь, максимум качества, экономия места) — их можно включать и выключать независимо.
